# Security policy

## Public repository boundary

Do not submit or publish credentials, cookies, access tokens, backup codes, phone numbers, account exports, customer data, browser profiles, logs, or private source code.

## Reporting a security issue

Please report security concerns privately via [@TheBotsLab](https://t.me/TheBotsLab) or [BotsLab@proton.me](mailto:BotsLab@proton.me). Do not open a public issue containing sensitive material.
